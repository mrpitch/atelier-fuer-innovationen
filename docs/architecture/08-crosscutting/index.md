# 08. Cross-cutting Concepts

Concepts that apply to two or more building blocks: the static export rule, section theming, content validation and security.

## Concepts

- [static-export-strategy](./static-export-strategy.md) — Why every building block must work without a server at request time, and what follows for search, images and routing.
- [section-theming-strategy](./section-theming-strategy.md) — How two complete palettes share one codebase through a data-section attribute.
- [content-conventions](./content-conventions.md) — The rules every Markdown and MDX file must meet, who checks them, and when the check runs.
- [security-strategy](./security-strategy.md) — Why the site has no run-time security surface, and where the remaining exposure sits.
- [security-conventions](./security-conventions.md) — Secrets, variables and supply-chain settings the build and deploy workflow depends on.
